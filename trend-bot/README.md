# ربات تلگرام یاب ویدیوهای ترند یوتیوب

کلمات کلیدی شما (یا کلمات استخراج‌شده از کانالتان) را در یوتیوب جستجو می‌کند، **Shorts را حذف می‌کند** و ویدیوهای پربازدید را بر اساس «بازدید نسبت به اندازهٔ کانال» رتبه‌بندی می‌کند تا ایدهٔ ویدیو بگیرید.

## منوی ربات
- 🔑 **کلمات کلیدی**: دکمه را بزنید و کلمات را (با ویرگول یا خط جدید) بفرستید. (فرستادن متن آزاد هم همین کار را می‌کند.)
- 📺 **کانال من**: هندل یا لینک کانال؛ کلمات از ۳۰ ویدیوی اخیر استخراج می‌شود.
- 📅 بازهٔ ۷/۱۴/۳۰/۹۰ روز، 🌐 زبان، 🚀 جستجو، 📄 خروجی CSV.
- 💡 **ایده‌های ویدیو**: بعد از جستجو، ویدیوهای ترند (و اگر کانال را ثبت کرده باشید، عنوان‌های خودتان) به Claude داده می‌شود و ۵ ایدهٔ تازه با عنوان، زاویه، هوک و طول پیشنهادی برمی‌گردد. «🔄 ایده‌های جدید» دوباره می‌سازد.

## راه‌اندازی
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید، `/newbot` بزنید و **توکن** را بردارید.
2. در [Google Cloud Console](https://console.cloud.google.com) یک پروژه بسازید، **YouTube Data API v3** را فعال و یک **API Key** بسازید.
3. این پوشه را در یک ریپوی GitHub (ترجیحاً خصوصی) قرار دهید.
4. در [Render](https://render.com): **New → Blueprint** → ریپو را انتخاب کنید (فایل `render.yaml` خوانده می‌شود).
5. مقادیر `TELEGRAM_BOT_TOKEN` و `YOUTUBE_API_KEY` را وارد کنید. برای دکمهٔ ایده‌ها، `ANTHROPIC_API_KEY` را هم بگذارید (از [console.anthropic.com](https://console.anthropic.com)؛ بدون آن دکمه نمایش داده نمی‌شود). `ALLOWED_USER_IDS` را فعلاً خالی بگذارید و Deploy بزنید.
6. وقتی بالا آمد، در تلگرام به ربات `/start` بدهید؛ **شناسهٔ عددی شما** را نشان می‌دهد. آن را در `ALLOWED_USER_IDS` (در Render → Environment) بگذارید و ذخیره کنید تا دوباره deploy شود. از این به بعد فقط شما به ربات دسترسی دارید و کسی سهمیهٔ یوتیوب‌تان را مصرف نمی‌کند.

## اجرای محلی
```
pip install -r requirements.txt
cp .env.example .env     # پر کنید
set -a; source .env; set +a
python bot.py            # بدون RENDER_EXTERNAL_URL به‌صورت polling اجرا می‌شود
```
نسخهٔ خط فرمان بدون تلگرام: `python trend_finder.py --channel @mychannel`

## نکات مهم
- **سهمیه**: هر کلمهٔ کلیدی ۱۰۰ واحد از ۱۰٬۰۰۰ واحد روزانهٔ یوتیوب مصرف می‌کند. نتیجهٔ هر جستجو ۶ ساعت کش می‌شود تا تکرار آن سهمیه نخورد.
- **پلن رایگان Render**: سرویس بعد از ۱۵ دقیقه بی‌کاری می‌خوابد و اولین پیام بعد از آن ممکن است تا حدود یک دقیقه دیر جواب بگیرد. همچنین دیسک موقتی است و تنظیمات ذخیره‌شدهٔ شما (کلمات/کانال) با هر ری‌استارت یا deploy پاک می‌شود. برای رفع هر دو، پلن پولی با Persistent Disk (و `PERSIST_PATH=/data/bot_state.pickle`) یا ذخیره در یک دیتابیس بیرونی لازم است.
- **Shorts**: ویدیوهای ≤ ۳ دقیقه یا دارای `#shorts` حذف می‌شوند.
- **هزینهٔ ایده‌ها**: کلید Anthropic API جدا از اشتراک Claude.ai است و هر بار ساخت ایده به‌صورت مصرفی حساب می‌شود (یک درخواست کوتاه). مدل پیش‌فرض `claude-sonnet-5-5` است و با `ANTHROPIC_MODEL` عوض می‌شود. ایده‌ها هم ۶ ساعت کش می‌شوند.
- عنوان‌ها و داده‌های یوتیوب در پرامپت داخل تگ‌های جدا و به‌عنوان «داده» به مدل داده می‌شوند، تا متن داخل عنوان یک ویدیو نتواند به مدل دستور بدهد.
